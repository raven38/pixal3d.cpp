Pixal3D Texture-1024 path on WebGPU (pixal3d_ss.wasm, pixal3d_texture_run)

Hand the module the texture flow GGUF and the hr_sample fixture (Shape-1024 token list, texture condition, noise, references); optionally the Shape-1024 stage's own final latent as the concat half. The sparse ProjectAttention texture flow (in_ch 64 / out_ch 32) and the Euler sampler run inside the WASM module on the ggml WebGPU backend. JavaScript only mounts the files and prints the report. Computing the texture condition in-page (DINOv3 at 1024², NAF at T=1024) needs the optional model files and is expected to exceed a 4 GiB adapter for now (docs/spec/32-texture-flow-webgpu-prep.md §7).
