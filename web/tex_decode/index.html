Pixal3D texture (PBR) decoder on WebGPU (pixal3d_ss.wasm, pixal3d_tex_decode_run)

Hand the module shape_dec.gguf, tex_dec.gguf and a real-SLAT fixture directory (coords, f32 shape SLAT, f32 texture SLAT, optionally the reference's f32_tex_coords / f32_tex_attrs for parity); the shape decoder runs first for its subdivision masks, then the texture decoder (from_latent, 4 x ConvNeXt stage + mask-driven C2S on the shared neighbor tables, final LayerNorm + 6-channel output_layer) runs inside the WASM module on the ggml WebGPU backend. JavaScript only mounts the files, prints the report and offers the raw attributes (attrs/coords .npy) for download; trellis-test-pixal3d-tex-decode --ext-attrs scores them natively.
