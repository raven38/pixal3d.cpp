Pixal3D shape decoder on WebGPU (pixal3d_ss.wasm, pixal3d_shape_decode_run)

Hand the module shape_dec.gguf and a real-SLAT fixture directory (coords + f32 shape SLAT, optionally the reference's f32_tex_coords for coordinate parity); the sparse decoder (from_latent, 4 x ConvNeXt stage + C2S on the shared neighbor tables, output_layer) and the dual-grid mesh extraction run inside the WASM module on the ggml WebGPU backend. JavaScript only mounts the files, prints the report and offers the raw mesh (verts/faces/coords .npy) for download; trellis-test-pixal3d-shape-decode --ext-mesh scores it natively.
